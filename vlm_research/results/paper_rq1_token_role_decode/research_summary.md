# Observation 2 中文研究总结

## 实验状态与结论

**已完成：200/200 张 COCO 图片、591 个冻结 Decode 位置、11,229 次真实单步干预。**
四卡均使用冻结采集代码 `13b2f575e0485dba89284d977855e34ab58b9701`，每卡 50 张。
LLaVA-1.5-7B revision `b234b804b114d9e37bb655e11cbbb5f5e971b7a9`；FP16/eager；Transformers 4.49.0。
Prompt 为 `Describe the image in one sentence.`，Greedy、KV Cache、最多 64 Token。
全部 200 条 Caption 正常 EOS，长度 11–26 Token，均值 16.915；没有截断或对齐失败。

**Observation 2 得到有限、条件性的支持，而非“功能词可跳过全部 Attention”的证明。**
主干预 Whole 的类别差异在控制置信度和位置后仍存在，主要集中于已测深层；
Image 直接贡献的 Visual–Function 全局差异经多重比较校正后证据不足。
All32 对功能词也造成严重影响，不能把单层低敏感性累加成全层安全省略。

## 数据与分类边界

- 200 图采用冻结输入哈希抽样，来自此前未执行的 COCO Confirmation 资源，与此前已完成的 400 图 COCO Discovery 无重叠；按 image ID、文件 SHA256 和 RGB 身份验证，不按输出选图。
- 三类各取每图最多一个完整、无歧义、单 Token 词；均在 `t>=1`。Function 200、Visual 199、Relation/Action 192，缺失的 1 个 Visual 与 8 个 Relation 不补造。
- Full 全部结束后、正式消融开始前统一冻结位置，选择不读取置信度、熵或干预结果。每图共享相对位置哈希锚点，但不保证词类位置完全一致，因此另行控制时间位置。
- 离线固定词表和优先级，Relation 优先于 Function；`on/in/with` 不重复归类。2477 个完整词中 356 个多 Token 词不进入主分析，没有把词尾作为独立词。
- Function 中冠词 `a/an/the` 为 104/200，`is/are` 为 35/200；Relation 中介词/空间词为 158/192、动作/状态词 34/192。这里不是均衡的动作动词实验。
- Visual 仅是视觉内容**候选词**，不是逐词 Grounding 标注。20 图上下文抽检确认对齐/优先级合理性，未改冻结标签；不将其冒充人工词性或 Grounding 准确率。

## 八项研究问题

### 1. Function 是否普遍更不敏感？

**总体均值更低，但不是每层、每词都更低。**
Whole 九层均值的同图主差异支持 H1；L0 的类别差异方向相反，L15 也不是 Visual 更敏感。
不能把平均关联写成词类的普遍定律，更不能写成单词是否“需要 Attention”的二元属性。

### 2. Visual Content 是否更依赖 Attention？

**相对 Function，Whole 主分析支持；对于直接图像来源，H2 仅有较弱、层相关证据。**
Image 的调整后差异为 0.003274，但校正区间跨零，不能称为已确证的全局类别优势。
图像信息可能早已进入其他文本状态，Image 条件测不到这些间接视觉路径。

### 3. Relation/Action 处于什么位置？

描述性地，Whole 均值 Relation 0.022061 略高于 Visual 0.019759；
Image 均值也较高，主要由 L14/L16 的正损失体现。
All32 则是 Visual > Relation > Function。
本类以介词为主，Relation 对比不属于预定的主推断 family，不宣称关系/动作词整体显著最敏感。

### 4. 结果是否集中在特定层？

**是，但不能照搬短答案首 Token 的中层峰结论。**
Whole Visual 在 L26/L31 的均值为 0.068550/0.078207；Visual−Function 分别为
0.050495 [校正CI 0.026054, 0.075549]、0.077453 [0.049961, 0.106563]。
这两个已测深层贡献了主要的类别差异。
Relation 的 Whole L14/L16 均值为 0.048750/0.043760；Image L14/L16 为 0.026571/0.039062。
Image 的 Visual−Function 仅 L26 校正区间为正，且下界接近零。
这只是九个预定层，不推测未测层峰值，不插值声称完整 32 层曲线。

### 5. 视觉来源 Attention 与完整 Attention 有什么区别？

Whole 与 Image 是不同干预，不是独立可加的信息归因。
同 Token 的 Whole−Image 九层平均差：Function 0.004925 [0.002884, 0.007036]、
Visual 0.017553 [0.014858, 0.020330]、Relation 0.014682 [0.012412, 0.017100]。
Function 的直接图像贡献带符号均值接近零，但完整 Attention 的影响更大，方向上与 H3 相容；
这不能单独证明“前文语言 Attention”是唯一原因，因为没有定向移除其他 Key，也存在非线性和间接视觉信息。

Image 条件严格减去原始 Softmax 权重与图像 V 的逐 Head 加权和经无 bias Wo 投影的贡献，
保留原始分母、非图像权重和投影 bias。没有重新 Softmax，也不等同于删除所有视觉信息。

### 6. 当前预测置信度能否解释类别差异？

Function 原生平均 LogP/Entropy 为 -0.6026/1.4669，Visual 为 -0.7603/1.9036；确实有难度混杂。
同图固定效应回归同时控制 Full LogP、Entropy、绝对和相对生成位置后，Whole 差异仍存在，
因此没有出现“差异完全被置信度解释掉”的情况 C。
主分析 Token 长度均为 1，该列不可估计、明确移除；不是声称估出了长度效应。
设计秩 6/6，条件数 10.996，10,000 个聚类 Bootstrap 均有效。
这是线性调整后的条件关联，无法排除词汇身份、句法上下文等未测混杂，不证明词性本身的因果作用。

### 7. 是否存在不需要当前步骤全部 Attention 更新的真实 Token？

**没有观察到满足冻结“近乎不变”联合标准的目标：三类都是 0。**
标准为 `abs_delta_logp<=0.01 AND Top1未变 AND JS<=1e-4`。
Function 有 20/200 保持原 Top-1，但其中许多概率/整分布仍大幅改变；不能据此称无需 Attention。
例如 `coco2014:431432` 的 `of` 在 t=10，All32 后 loss=-0.124126、Top-1 未变，
但 JS=0.313545，不是“无影响”；`coco2014:179199` 的 `is` loss=0.058383、JS=0.352966。
这些是事后示例，不替代全部分布。

反例非常强：190/200 个 Function 的 loss>=1 nat；最大反例为 `coco2014:354729` 的 `its`，
loss=11.140736，原 Token 概率从 0.923119 降至 0.000013394。
所以 H4 在本次冻结样本和严格标准下未获支持，不能宣称功能词可安全跳过全部新 Attention。

### 8. 最终 Observation 2 应当如何表述？

**部分成立。** 建议论文表述：

> 在 LLaVA-1.5-7B 的原生 COCO Caption 生成轨迹上，冻结词表标记的完整单 Token
> 在当前 Decode 步骤的 Attention 消融敏感性随信息角色和层深变化。
> 视觉内容候选词相对功能词的 Whole 单层平均 LogP 损失在同图、置信度及位置控制后仍更高，
> 该差异主要出现在已测深层。直接图像贡献的全局类别差异证据较弱；
> 功能词在 All32 消融下仍普遍严重受损，因此词类低敏感性不能推出全层 Attention 可省略。

H1 得到条件支持；H2 不足以作强全局结论；H3 方向相容但信息路径未被单独验证；H4 未获支持。
这不是完整答案准确率、Grounding 质量、因果词性效应、算子实际跳过或推理加速的证据。

## 正确性、成本与可复现性

- CPU 采集测试 12 项、统计测试 4 项均通过；四卡独立真实 Smoke 通过。
- 每卡原生 `model.generate` 与采集生成 Token 完全一致；全部正式 Full 重放逐步 Logits bit-exact。
- No-op / Image observer Logits bit-exact；逐层原始图像贡献数值分解 144 项检查通过。
  最大 head 误差 0.000976、投影误差 0.003485；对应冻结逐元素传播界的最大比例为 0.8862/0.0844，未拟合或放宽容差。
- 591 次目标前后父 Cache SHA256 一致；每条件独立深克隆，时间对齐显式检查，干预后立即丢弃新 Cache。
- 无 NaN/Inf/OOM、失败样本或残留 Hook；模型参数版本、输入哈希及第三方源码绑定检查通过。
- 404 个原始 Logits NPZ（约 1.085 GB 十进制）已复核 SHA256；另从每卡固定一图抽取三个条件，在 CPU 精确重算 12 条原始指标。
