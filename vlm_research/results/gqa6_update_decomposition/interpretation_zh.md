### 1. 早层 Attention 是否小？

**绝对范数小，但相对更新并不小。** L0–L4 与 L12–L18 的 Attention 范数差为 −8.3855，95% CI [−8.4417, −8.3286]；Attention 比例差却为 **+0.2822 [0.2802, 0.2843]**。六任务的对应比例差全部为正，范围约 0.2702–0.3044。

其中 L0 的输入残差范数仅 0.5916，Attention 比例达到 1.5434；L1–L4 也分别为 0.5003、0.5169、0.4548、0.3741。因此早层较小的原始范数不能脱离残差尺度解释，低消融敏感性不能简单归因于相对更新幅度小。

### 2. 早层 MLP 是否比 Attention 大？

**不能笼统地说早层 MLP 更大。** L0–L4 的平均 MLP 比例 0.7427 高于 Attention 的 0.6779，配对差为 +0.0648 [0.0614, 0.0682]，六任务方向一致；但早层平均原始 MLP 范数反而更小，1.2365 对 1.3223。

这不是计算矛盾：先在每层除以不同大小的输入残差再平均，与直接平均原始范数不是同一个估计量。逐层看，MLP 在 L0 明显更大（比例 2.1493 对 1.5434），在 L1–L3 则小于 Attention，L4 再略大。早层平均比例的正差不能被解释为每个早层都由 MLP 主导，更不能证明 MLP 的因果重要性更高。

### 3. L14–L16 是否局部增强？

**有描述性支持，但不是全局更新峰。** 预先固定的 L14–L16 Attention 比例减去 L12/L13/L17/L18 比例，差为 +0.0672 [0.0638, 0.0705]，六任务差均为正（0.0277–0.1218）。

局部均值 0.4341 仍低于 L0 的 1.5434、L9 的 0.7392；不能据此把原消融敏感峰解释为全网最大的 Attention 相对更新。L14 的比例 0.5351，L15/L16 为 0.3802/0.3869，峰值位置也并非所有任务逐层完全重合。

### 4. 敏感峰与方向是否有特殊对应？

L14/L15 的 Attention 与输入残差近乎正交或略反向（平均 cosine −0.0064、−0.0539）；L16 转为正向 0.1763。L14–L16 的平均 Attention–MLP cosine 为 −0.1246，存在方向上的负对齐，但其他中层也有更负的对齐，例如 L6 为 −0.4035。因此这不是敏感峰独有的几何特征。

严格匹配 100 题后，Attention 比例与原有带符号 `Delta LogP = ablated − Full` 的相关性较弱。六任务合并、按 task 和 layer 去均值后 Pearson 为 −0.0418，Spearman 为 −0.0211。该计算不是偏相关因果模型，重复题/层行不独立，也不产生显著性结论。更新范数或方向不足以单独解释敏感性。

### 5. BOS Mass 能否解释低敏感？

**BOS Mass 与 Attention 更新比例存在负相关，但与消融敏感性的关系仍弱。** 对严格匹配的样本，合并结果如下；符号遵循原始 Delta LogP，未将其取负或取绝对值。

| 变量对 | 32 层均值 Pearson / Spearman | task、layer 内去均值 Pearson / Spearman |
|---|---:|---:|
| BOS Mass / Attention 比例 | −0.6985 / −0.6650 | −0.4324 / −0.4252 |
| BOS Mass / MLP 比例 | −0.6798 / −0.6899 | −0.0069 / −0.0311 |
| BOS Mass / Delta LogP | +0.2162 / +0.3823 | +0.0367 / +0.0331 |
| Attention 比例 / Delta LogP | −0.0737 / −0.1092 | −0.0418 / −0.0211 |

跨层均值相关容易受深度趋势影响，尤其不能把 BOS–MLP 的跨层关系当作稳定样本级关系。BOS–Attention 比例关系在 task/layer 内仍存在，但 **“BOS 高 → 更新小 → 消融无害”这条机制链没有被本轮建立**。早层总体 BOS 也低于深层，L0 的 BOS Mass 约 0.0023，不能用统一的“早层 BOS 主导”概括全部早层。

### 6. 深层与中层有何不同？

L25–L31 的 Attention 比例明显下降至 0.1019，中层为 0.3957；配对差 −0.2937 [−0.2957, −0.2918]。但其 Attention 原始范数并不更小，12.8102 对 9.7078，说明残差流尺度增长是必须考虑的结构差异。

深层平均 Attention–Residual cosine 为 0.4125，中层为 0.0712；Attention–MLP cosine 从 −0.1334 变为 +0.0981。Cancellation 从 0.6648 升至 0.8030，数值更高表示方向抵消相对更弱，不是更强。

最后一层必须单独注意：L31 MLP 比例达到 0.9842，原始范数 157.4051；输入输出 cosine 从 L25–L29 的约 0.97–0.98 降至 L31 的 0.7718。因此不能把深层均值解释为所有深层都只有很小的净更新。

## 假说判断与后续价值

- **不支持：** 早层低敏感可以简单归因于 Attention 相对更新很小。
- **部分支持：** 早层平均 MLP 比例高于 Attention，但主要受 L0 影响，不支持逐层一致的 MLP 主导。
- **支持局部描述：** L14–L16 相对邻近层有 Attention 比例增强；深层存在较低 Attention 比例及不同的方向结构。
- **不支持作为充分解释：** 单靠 BOS、更新范数或 cosine，就能解释原消融敏感性或证明 MLP 补偿。

**值得继续研究，但应转向“更新内容和后续传播为何与更新幅度解耦”，而不是继续假定早层更新幅度小。** 本轮没有执行后续干预；这些结果不能证明 Attention 冗余、MLP 因果补偿、整层可安全跳过或实际加速，也不外推到 Decode、其他模型或总体 GQA 性能。
