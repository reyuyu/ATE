# Complete Six-Task Single-Layer GQA Experiment

Start with the [research readout](research_summary.md) for the measured results,
limitations and artifact index. The immutable [generated report](report.md)
contains the original completion summary and all seven figures. Every figure
is also provided as PDF under [figures/](figures/).

The experiment completed 3,000 main questions and 480 predefined exploratory
generation questions on four GPUs. Original completion hashes and numerical
replay are retained unchanged; the review manifest separately binds the
post-run readout and resource-release audit. Historical experiments and main
were not modified.
