- 每个案例的 `all32_views.pdf` 有三页：共享对数叠加、局部增强叠加、共享对数纯热图；对应 PNG 也全部保留。

## 色标含义

**共享对数色标版**使用视觉内部条件概率，即 Patch 原始概率除以当层 Image Mass。对每个案例，在全部32层上确定同一正值最小值/最大值，再用对数色标展示。它使弱信号可见，但不修改数据；图中 M 始终显示原始 Image Mass。不同案例各自有色标，不应直接比较颜色。

**局部对比增强版**对每层分别使用2%–98%分位显示区间，将两端截到显示范围。仅仅增强空间形状可见度，色条是“显示强度”，**不是概率，也不能跨层比较颜色强弱**。这版不应冒充“同一色标”的定量对比图。

原先的原始概率/线性色标正文图和3000题总体三曲线均保持不变。既没有人工移动热点，也没有让背景热点变成目标对象热点。上采样不创造高于24×24的真实空间分辨率；CLIP裁剪外仍是未观测区域。

## 自行选图

先打开目录中的32层总览，记下 **QID + Layer**，再取相应 `Lxx.png` 或原始 Patch 数据。若最终根据这些图更换正文案例或层，论文应注明“事后用于展示的可视化选择”，不能称作预先冻结的无偏案例；总体3000题统计不受选图影响。

全部显示参数、原始检查点哈希记录在 `all_layers/display_manifest.json`。原实验产物索引与新增图集索引分开保存；新增内容不覆盖原实验结论。

复现（CPU绘图，无模型加载）：

```bash
cd vlm_research
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m first_answer_mass.all_layers
```
