# Execution Notes

- Only physical GPU0 was used, under the user's earlier explicit GPU0/1 authorization. GPU1/2/3 were not used or terminated.
- Official COCO annotations were not present locally. Only the compressed `instances_val2014.json` member was fetched by HTTPS byte range from the official COCO S3 bucket, with ZIP CRC and content SHA recorded. No image dataset or model was downloaded.
- The initial `images.cocodataset.org` HTTPS endpoint failed certificate validation; TLS verification was not disabled. The official S3 endpoint succeeded. An additional metadata request encountered a connection reset; it was not used as an experimental result.
- The first new CPU uniform-attention statistics test exposed FP32 accumulation error. Statistics aggregation was corrected to FP64 without relaxing its tolerance. `cpu_tests_attempt0.log` is retained; the final inference/regression suite has 38 passing tests. Network/model inference remains the frozen FP16 path.
- All 84 formal generations completed without a GPU runtime failure, NaN, Inf or OOM. Strict historical Token IDs and first-answer logits were reproduced for both C3 and E1 on all three cases. The read-only observer preserved every generation step's logits exactly.
- CPU-only figure review found cramped labels and an overlapping color bar. Only CPU analysis/plotting code was changed after inference was frozen, with saved probabilities aggregated in FP64; captured probabilities and generation checkpoints were not changed. The final layer galleries and main figures were regenerated and visually reviewed.
- The first final-audit attempt rejected a test-count mismatch: passing both the parent test module and its importing child module produced 50 executions rather than the canonical 38. The canonical `reverse_writer.tests` plus `pope_instruction_probe.tests` command was rerun. This bookkeeping rejection is retained in `audit_results_attempt0.log`; it did not trigger GPU work or change results.
- Dense reference equivalence uses the unchanged historical shape-changing FP16 tolerance, not bit equality. Native/No-op, observer/unchanged engine, and historical binding comparisons use exact equality. These are distinct checks.
- The roughly 62-second GPU worker time does not include source reading/implementation, annotation acquisition, CPU tests, complete per-token/head galleries, audit or Git upload. No inference timing or speedup claim is made by this interpretability experiment.
