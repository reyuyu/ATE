Figure 3. Layer-wise necessity of visual writing on the same six-task GQA cohort (3,000 questions; 2,409 image SHA256 clusters). Rows show LLaVA-1.5-7B (32 layers), Qwen3-VL-8B (36 layers), and InternVL3-8B (28 layers). In every condition, the original last prefill query (P−1) and all autoregressive decoding queries cannot directly attend to original image keys. All-Writer retains visual access for every post-image, pre-P−1 text/template query R; it is not Native Full. (a) Each measured point is ACC(All-Writer) minus ACC(Drop-Li), in percentage points, for one task; negative values indicate improvements after the ablation. (b) Answer damage is 100 times the number of All-Writer-correct answers made incorrect by Drop-Li, divided by the task's All-Writer-correct count. All rows share a blue 0–10% scale; triangles and numeric labels explicitly identify values above 10%. Orange dashed lines mark the original preselected deep-layer boundary; the additional green dotted line at L20 marks the post hoc InternVL boundary. (c) All-Writer versus joint visual-writing restriction at L20–L31, L22–L35, and L17–L27, respectively. Bars report overall accuracy; ordinary paired 95% image-cluster bootstrap intervals for the differences are provided in the accompanying data and report. LLaVA/Qwen values are read from pinned historical CSV files; InternVL is newly measured with 20,000 paired image-cluster bootstrap resamples. Single-layer analyses additionally report Bonferroni-28 intervals for InternVL. Each model retains its own native prompt, architecture, and visual-token budget (LLaVA: 576; Qwen: native variable image tokens and mRoPE/DeepStack; InternVL: one 448-pixel tile, 256 image tokens). These dense permission interventions establish functional effects and do not measure physical pruning, cache compression, or speedup. LLaVA uses FP16, whereas Qwen and InternVL use BF16; the historical Qwen run uses Transformers 4.57.6 and InternVL uses 4.49.0. Cross-model differences are descriptive and do not isolate architecture from preprocessing, precision, software, or prompt differences. The third InternVL bar (L20–L27 OFF, asterisk) is an additional user-requested exploratory condition selected after the original L17–L27 result was known. It uses the same 3,000 inputs, model, GPU UUID, and frozen generation protocol, with 3,000 new generations and reused All-Writer/Keep-L0-L16 references. Its paired confidence intervals are ordinary unadjusted 95% intervals and do not establish equivalence. Original panels (a) and (b) and the LLaVA/Qwen measurements are unchanged.
