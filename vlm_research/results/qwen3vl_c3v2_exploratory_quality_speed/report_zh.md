# Qwen3-VL C3-V2：探索性质量与真实速度评测

结果基于1000道冻结GQA val_balanced问题（918张图），四条件4000份独立完整生成；48张图同时测试自然EOS和固定16 Token，各条件预热2次、测量5次。本轮为探索性评测，旧严格BF16 Logits门槛失败记录保持原样，不作为本轮质量结论的通过证明。

## 直接回答

1. **原始物理C3相对Native**：590/1000（59.000%）对694/1000（69.400%），Δ=-10.400pp，95%CI [-12.727, -8.141]；原对变错127题、原错变对23题。
2. **原始物理C3相对Dense F**：590/1000（59.000%）对588/1000（58.800%），Δ=+0.200pp，95%CI [-0.299, +0.701]；原对变错2题、原错变对4题。
3. **数值修复相对原始物理版**：585/1000（58.500%）对590/1000（59.000%），Δ=-0.500pp，95%CI [-1.107, +0.099]；原对变错7题、原错变对2题。

4. **真实E2E速度**（>1表示加速，<1表示变慢）：
   - Physical-Original：自然EOS 1.204×（95%CI [1.172, 1.235]）；固定16 Token 1.174×（95%CI [1.171, 1.176]）。
   - Physical-Repaired：自然EOS 1.071×（95%CI [1.030, 1.108]）；固定16 Token 1.034×（95%CI [1.028, 1.041]）。

5. **后续版本选择**：本批数据中修复版未增加正确数且更慢，原始物理版更值得作为后续优化起点；严格数值一致性失败仍保留，不把本结论当作数值验收通过。

原始物理版相对Native仍损失10.400pp，不能作为近无损替代。版本选择仅指本批质量—速度权衡，未授权或执行进一步修复、调参或搜索。若某速度比低于1，明确表示该场景没有实现加速。

## 四条实现路径与正确性

- Native为原生完整Qwen3-VL；Dense F保留稠密计算，仅实施既有C3功能干预。
- Original严格使用基线原始`Execution C`，L1–L6真实Attention跳算、L22视觉Hidden退出、紧凑文本KV。
- Repaired保留既有早层dead-key、Decode zero-image、L22–L35 Prefill zero-image，以及四个投影的固定cuBLASLt方案。未增加Kernel搜索、精度变更或新修复。
- 为公平测速，仅移除修复实现中的只读检查、日志及逐层计时探针；20题对比审计开/关的全部有效Logits严格相同，另对每卡最短/最长Smoke共4题与冻结debug修复路径逐位相同。
- 两卡各10题Smoke，Native/No-op全部有效Logits严格`torch.equal`；Mask禁用概率为0、36层MLP/Norm与残差检查、mRoPE绝对位置、DeepStack和Hook释放通过。物理路径保留真实Skip/视觉Hidden退出/紧凑持久KV。
- 自由生成均为BF16/Eager、greedy、max_new_tokens=32、logits_to_keep=1，每请求独立Cache；所有4000条逐步检查有限Logits。未重复追求旧F/C数值误差门槛。

## 测速边界与内存

计时为同步的模型请求E2E墙钟，包含CPU输入Tensor传入GPU、Vision、执行/Cache/Hook上下文建立、Token选择、EOS判断与上下文清理；不包含磁盘图片读取、Processor预处理、模型加载及计时后的文本解码。因此不是用户从文件到字符串的全服务延迟。所有条件使用同一计时入口、相同设备、相同样本，按冻结循环顺序交替测量。固定16含Prefill预测的第一个Token及15个真实增量Decode，忽略EOS停止仅用于等长度速度控制；不用于Accuracy。自然EOS的输出长度不同，速度同时受答案长度影响。

每题先将5次重复折叠为中位数，再以Native总时间/方法总时间计算速度比；48张不同图片整簇Bootstrap形成速度CI，不把240次重复当作独立样本。计时无审计探针，另在计时外检查有效Logits有限及Token与未计时参考一致。GPU事件分别测Vision、首Forward（TTFT GPU）、增量Decode；Prefill language=TTFT GPU−Vision。48题按输入长度跨度冻结选择，测速结论限于此子集、两张RTX3090及batch=1，不是生产工作负载总体估计。

## 数据冻结与限制

官方注释共有132062题、10234张图，本地图片全部可用。使用与输出无关的SHA规则抽1000题，未改变Prompt、Processor、图像分辨率或选层；不是新独立确认实验，历史研究中可能见过部分图片。Image Token数随原始Processor变化，输入长度覆盖92–1105，未强制为历史96 Image Token。

完整答案使用既有固定GQA转换`text.rstrip(".").lower()`后与官方短答案做完整字符串匹配；没有首词截断或新答案解析器。所有条件使用同一评分。任务分组沿用官方types.semantic，见`task_accuracy.csv`。

原始逐请求输出与Token在`checkpoints/`，全部计时重复在`benchmark/`，SHA索引及`validation.json`用于复核。冻结模型资产、输入、协议、执行源码和cuBLASLt桥接二进制哈希均保存。本轮只完成所要求的探索性质量与速度测试，停止后续修复及搜索。

## 复现资产与实现开销

测速关闭可选的逐层审计Hook和修复路径只读探针；继承的原始物理执行器仍含绝对位置、Cache容量等断言，均作为当前实现开销计入E2E。本结果不是理想Kernel或实现性能上界。未修改继承的Original源码来追求更高速度。

本次全部逐请求答案、Token、计时与CSV随独立分支交付。模型权重、原始图片及既有cuBLASLt桥接共享库保留在服务器资源目录，不宣称GitHub包含这些资产；其路径及SHA绑定见模型、输入与源码冻结清单。Smoke保存有效Logits的SHA及严格比对记录，避免新增大规模冗余Logits归档。
