# 核心判读：角色依赖部分复现，不能宣布安全旁路

## 1. R是否明显更敏感？

是。在固定240题中，Qwen R-Bypass相对Full降低27.917个百分点，损害73题、纠正6题。
R相对I为−24.583个百分点，图像簇配对95%CI为[−31.250, −18.333]；相对A为−27.083个百分点，CI为[−33.750, −20.417]。
七项Bonferroni校正区间也均排除0，支持后图像文本Query更新具有更大的整体行为贡献。
这里的R包含Question和后图像模板文本，不等同于只关闭Question Token；不同角色Query数量也不同。

## 2. 是否完整复现“Image低敏感、Text高敏感、Answer低敏感”？

只能称为**相对敏感性模式的部分复现**。
Qwen A相对Full下降0.833个百分点、损害2题；R的损害远大于I/A，与LLaVA方向一致。
但Qwen I下降3.333个百分点，损害9题、纠正1题，普通95%CI[−5.833, −0.833]排除0，不能描述为近乎无损。
七项校正区间为[−7.083, 0.000]；这不抹去已观察的9个真实损害，也不能据此证明安全。
同题LLaVA I仅净降0.833个百分点；本轮Qwen图像Query的整体依赖更明显，但模型、层数、原生Prompt及精度不同，不能把差异单独归因于某一个架构因素。

## 3. I+A联合是否仍低敏感？

相对R，其损害明显较小；但没有证据支持严格无损或预设容忍范围内的非劣效。
I+A下降2.500个百分点，损害8题、纠正2题，普通95%CI[−5.000, 0.000]，校正CI[−6.250, 0.833]。
联合独有损害为0，只说明本批没有出现“Full、I、A均对而I+A独错”的样本，不代表不存在一般风险。
交互IA−I−A+Full为+1.667个百分点，95%CI[0.000, 3.750]，包含0，不宣称可靠的协同纠错或补偿机制。

## 4. 对Role-Aware推理优化的依据

本轮支持保留后图像文本Attention更新、按Query角色研究计算预算的**因果方向依据**。
它不支持直接把L1–L6图像或图像+答案Attention作为无损路径删除。
本实验只是o_proj输出干预，Q/K/V、Attention、KV、DeepStack、MLP仍原生执行，没有实现或测量真实推理加速。
未扩样、未训练、未实现Kernel，也未追加层段或联合条件；实验到此停止。

完整数字、首Token变化、LogP、任务分组和负面案例见同目录`report_zh.md`与CSV。
