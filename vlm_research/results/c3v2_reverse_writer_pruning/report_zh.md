# C3-V2反向视觉Writer剪枝实验

状态：COMPLETE。冻结3,000题、7条件；完成21,000/21,000条。数据源与选样在正式推理前固定，不根据结果改规则。

C3为原始C3-V2 All-Writer；E1只禁止Instruction直接读图；E2-Pk额外禁止ASSISTANT前k个Subword；E2-S2额外禁止最后2个Subword。文本、Prompt和位置从未删除或改写。P−1始终不是可读图Writer。

## 核心结论

- **E1是本轮更保守的反向剪枝候选，但不是已经证明的通用无损规则。** 相对C3，GQA/VQAv2/TextVQA的点估计为+0.50/+0.54/+0.42pp，ScienceQA为−0.60pp，POPE三策略均为−1.67pp。E1的家族校正区间均包含0，既不能据此宣布无损，也不能把共享图片的POPE三策略当作三次独立确认。逐题损害必须保留。
- **继续删除ASSISTANT不能作为默认安全优化。** 预声明的E2-P2−E1在VQAv2为−3.46pp，Bonferroni14校正95%CI为[−6.380,−0.974]；TextVQA为−2.86pp，校正CI为[−5.799,−0.181]。本探索队列中，该增量干预有明确负向证据。删除全部四个Subword相对E1更分别下降8.76和10.34pp。
- **数量和位置都可能影响结果，而且并非所有任务单调一致。** 同预算前2 OFF较后2 OFF，在GQA点估计低1.50pp，在POPE Random/Popular低2.33pp；这些位置比较只有探索性普通区间，不能升级为确认性结论。ScienceQA反而在前4 OFF时达到64.60%，说明不能预设统一的Subword重要性排序，也不据此为ScienceQA另立规则。
- **目前不足以用E1/E2通用替代Conditional-15或All-Writer。** 本轮没有重测Conditional-15公平对照；E1值得作为固定结构候选进一步验证，但没有完成新的独立外部确认，更没有跨任务非劣效认定。本轮到此停止。
- **没有新增物理计算节省。** 21,000条记录的KV容量逐题核对均与C3完全相同。Dense Mask不减少QKV、QK/AV或输出投影执行形状；新增矩阵FLOPs节省为0。观察性时延不能证明新的E2E加速。

软分任务的下降/上升是逐题分值变化，不强行二值化；二值任务对应原对→错/原错→对。配对CSV的decreased/increased始终指这些逐题生成分数变化；POPE的F1、Precision、Recall是按重采样混淆总数重新计算，不能把该列当成F1等汇总率的单题分解。完整损害与纠正均保留在CSV。

Native辅助比较只接受严格统一H1及输入绑定的历史记录：ScienceQA/POPE覆盖全样本；GQA、VQAv2仅覆盖可验证H1子集，具体n见native_accuracy_auxiliary.csv与每项配对CSV，不能套用到完整600/500题。TextVQA没有可严格绑定的H1历史基线，本轮不额外生成Native，不使用不一致历史分数。

具体而言，Native H1覆盖GQA 414/600题、VQAv2 200/500题。旧60题VQAv2 Pilot的Native 85.50%与C3-V2 81.67%不能直接作为本轮500题的对照；本轮完整C3-V2 70.78%对应的是不同规模的冻结队列，不是改变评分或筛掉失败样本。

## 研究问题

1. Instruction的直接视觉读取并非可预设无用。仅删除Instruction最明显的点估计损害在pope_random（-1.667pp），另一端为VQAv2（+0.540pp）。是否存在可检出的群体损害须结合校正区间，不能只看均值。
2. ASSISTANT前缀阶梯与后缀两Token对照使用固定原生四个Subword及真实Offsets，位置对照见E2-P2−E2-S2。差值不等同于某Subword存储了独立视觉语义；非线性联合与概率重分配都可能参与。
   scienceqa_img：前2 OFF − 后2 OFF = -0.400pp，普通95%CI [-1.008, 0.000]（探索性）。
   pope_random：前2 OFF − 后2 OFF = -2.333pp，普通95%CI [-4.333, -0.667]（探索性）。
   pope_popular：前2 OFF − 后2 OFF = -2.333pp，普通95%CI [-4.333, -0.667]（探索性）。
   pope_adversarial：前2 OFF − 后2 OFF = +0.000pp，普通95%CI [-2.333, 2.333]（探索性）。
   VQAv2：前2 OFF − 后2 OFF = -1.680pp，普通95%CI [-3.600, 0.180]（探索性）。
   textvqa：前2 OFF − 后2 OFF = -0.620pp，普通95%CI [-2.625, 1.361]（探索性）。
   GQA：前2 OFF − 后2 OFF = -1.500pp，普通95%CI [-2.667, -0.333]（探索性）。
3. 接近C3的点估计不能证明通用替代Conditional-15；本轮未新增Conditional-15对照，不将历史不同输入配置的分数拼接为公平优势。它提供固定结构Mask的跨任务探索结果，而不是已验证的新最优选择器。
4. 本轮Instruction/ASSISTANT裁剪仍执行Dense Attention。与C3相同输入和生成长度时，Q/K/V/o及QK/AV矩阵形状、KV结构不变，新增物理FLOPs节省为0。Writer预算下降不能称为真实加速。quality-run时延仅作观察性诊断，未经预热交错测速，不报告新增加速倍数。

这些结果只解释C3-V2背景下指定直接路径的功能干预，不证明某类文本没有视觉语义。Hard Mask使原概率重新分配到保留的文本、BOS与Self；其他文本中继、残差和后续层仍可能携带视觉信息。不同条件的损害不能简单相加。POPE保留官方词法规则，即使空字符串可能被解析为yes，也单独保留空答案标记，不修补得分。
